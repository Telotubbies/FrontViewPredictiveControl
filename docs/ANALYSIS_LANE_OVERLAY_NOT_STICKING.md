# วิเคราะห์: กรอบเขียว (lane overlay) ไม่แนบถนน

## อาการจากภาพ (Dashboard)

| ส่วน | สิ่งที่เห็น |
|------|-------------|
| **Perception - UNet Lane (กล้องหลัก)** | กรอบเขียวกว้างเกิน ไม่แนบขอบเลนจริง โดยเฉพาะด้านซ้ายยื่นไปทางไหล่/ไหล่ถนน |
| **Planning - Bird's Eye** | เส้นน้ำเงิน (reference path) แคบและอยู่กลางเลนสมเหตุสมผล |
| **Perception - BEV** | เส้นเหลือง/เขียว/น้ำเงิน (L/R/center) ชัดและแคบกว่า overlay ในกล้องหลัก |
| **ความเร็ว** | 7.9 km/h (โหมดทดสอบช้า) |

สรุป: **การวางแผน (MPC/WP) ใช้ path แคบอยู่แล้ว แต่กรอบเขียวที่วาดบนกล้องหลักกว้างและไม่ตรงขอบเลน**

---

## สาเหตุจาก Config และ Logic

### 1. ช่วงใกล้ตัววาดเป็น “กล่องตรง” (Straight near)

- **Config:** `LANE_OVERLAY_STRAIGHT_NEAR_M: 6.0`
- **Logic:** ระยะ 0–6 m จากตัวรถวาดเป็น **เส้นตรง** โดยใช้ `± strip_half_width` (0.9 m) = ความกว้าง 1.8 m คงที่
- **ผล:** ไม่ได้ตาม left/right ที่จับได้จริง → ใกล้หน้ารถจะเห็นเป็น “กล่อง” กว้างคงที่ ไม่แนบเส้นปะ/ขอบถนน

### 2. Margin บวกทั้งสองข้าง

- **Config:** `LANE_OVERLAY_DISPLAY_MARGIN_M: 0.2`
- **Logic:** `y_l_draw = y_l - margin_m`, `y_r_draw = y_r + margin_m` (ในโหมด edge-fitting)
- **ผล:** กรอบกว้างขึ้นอีก 0.4 m รวม → ดูไม่แนบขอบเลน

### 3. บังคับความกว้างขั้นต่ำ (Min display width)

- **Config:** `LANE_OVERLAY_MIN_DISPLAY_WIDTH_M: 2.0`
- **Logic:** ถ้า `width_at_ego < 2.0 m` จะใช้ center ± 1.0 m แทน left/right จริง
- **ผล:** ในเลนแคบหรือตอนจับได้แคบ กรอบจะถูกขยายเป็น 2 m → ไม่แนบขอบถนน

### 4. แหล่งข้อมูลซ้าย/ขวา (BEV → coeffs)

- Left/right มาจาก BEV sliding window + polynomial fit
- ถ้า peak เลือกผิด (เช่น rightmost peak ไปกินขอบถนน/ไหล่) หรือ fit กระจาย → coeffs กว้าง/เบี่ยง → overlay ที่อิง left/right ก็กว้าง/ไม่ตรงขอบไปด้วย

## แนวทางแก้ (เรียงตามผลต่อ “แนบถนน”)

### A. ลด margin (ให้กรอบแคบลงและแนบขึ้น)

- `LANE_OVERLAY_DISPLAY_MARGIN_M: 0.2` → `0.0` หรือ `0.05`
- กรอบจะไม่บานออกจากขอบเลนที่จับได้

### B. ลดหรือปิด “straight near” (ให้ใกล้ตัวก็แนบ coeffs)

- `LANE_OVERLAY_STRAIGHT_NEAR_M: 6.0` → `2.0` หรือ `0.0`
- ค่าเล็ก = ใช้ left/right coeffs ตั้งแต่ใกล้ตัว → กรอบแนบเส้นปะ/ขอบถนนมากขึ้น ไม่ใช่กล่องตรง 1.8 m

### C. ลด min display width (ให้เลนแคบได้ตามที่จับได้)

- `LANE_OVERLAY_MIN_DISPLAY_WIDTH_M: 2.0` → `1.2` หรือ `1.0`
- ใช้บังคับขยายเฉพาะเมื่อจับได้แคบมาก เพื่อไม่ให้กรอบบานเมื่อเลนแคบจริง

### D. ตรวจ BEV / sliding window (ถ้ากรอบยังเบี่ยงหรือกว้างผิดปกติ)

- ดูว่า rightmost peak / left peak ไปจับขอบถนน/ไหล่หรือไม่
- ดู polynomial order และ smoothing (EMA) ว่าทำให้เส้นบานหรือเบี่ยงไหม

---

## สรุปหนึ่งบรรทัด

กรอบเขียวไม่แนบถนนเพราะ (1) ช่วงใกล้ตัวถูกวาดเป็นกล่องตรง 1.8 m (2) มี margin 0.2 m ต่อข้าง (3) บังคับความกว้างขั้นต่ำ 2 m — แนะนำลองลด margin, ลด straight_near_m และลด min_display_width ก่อน แล้วค่อยปรับ BEV ถ้ายังไม่ตรงขอบถนน
